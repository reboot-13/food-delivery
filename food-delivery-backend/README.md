Food Delivery Backend

Stack:
- Kotlin
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- Flyway
- JPA (Hibernate)

Implemented:
✔ Registration
✔ Authorization
✔ JWT authentication
✔ Product catalog
✔ Categories
✔ Order creation
✔ Order history
✔ Order details

Run:
1. Create PostgreSQL database "food_delivery"
2. Copy application.properties.example to application.properties
3. Fill your DB credentials
4. Run application
